### Projetos

**[portfolio-v2](https://github.com/michellycruz/portfolio-v2)** — `React` `TypeScript` `Tailwind` `Go`
Portfólio reconstruído do zero com frontend em React + TypeScript e backend próprio em Go,
com envio de contato por SMTP.

**[Hostbraza Avisos](https://github.com/michellycruz/hostbraza-avisos)** — `PHP` `WordPress`
Plugin que centraliza avisos de hospedagem (domínio expirando, conta a vencer, disco cheio)
num banner do `wp-admin` e em notificações no site, visíveis só para administradores. Toda a
leitura passa por uma única função, então a origem dos dados troca de cadastro manual para
API externa sem mexer no resto do plugin.

**[projetos_javascript](https://github.com/michellycruz/projetos_javascript)** — `JavaScript` `HTML` `CSS`
Conversor de unidades, galeria com lightbox, gerador de paleta de cores e outros projetos
pequenos de JavaScript puro, cada um com a página no ar.
